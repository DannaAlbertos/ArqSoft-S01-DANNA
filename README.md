# Catálogo de Carros Deportivos 
## Descripción del Proyecto

Este es un catálogo interactivo de carros deportivos desarrollado como **proyecto escolar**. La aplicación presenta una colección de los carros más icónicos y rápidos del mundo, permitiendo a los usuarios explorar sus características técnicas, filtrar por marca y tipo de motor, y aprender datos interesantes sobre cada vehículo.


## Tecnologías Usadas

### Frontend:
- **HTML5** - Estructura semántica y accesible
- **CSS3** - Estilos avanzados con:
  - Gradientes dinámicos
  - Animaciones keyframe personalizadas
  - Variables CSS para temas personalizables
  
- **JavaScript (Vanilla)** - Funcionalidad interactiva sin dependencias externas:
  - Event listeners y delegación de eventos
  - Intersection Observer API para animaciones al scroll
  - Filtrado dinámico de datos
